# preview.6：大屏设置局部灰线的绘制隔离试验

根因尚未证实，不能宣称视觉缺陷已经修复。原截图局部线约在 x=438/1440，报告修掉的宿主侧栏边界约在 x=325/1440，两者不是同一条。

源码核查：openSettings 会 setView('bar') 后打开设置，正常路径不会把看板抽屉留在背后。设置内容是带 transform 的 fixed 对话框内的滚动层。此次仅在 ≥1024px 且（高≥600px 或 pointer:fine）时，对设置的直接内容层施加 isolation:isolate 与 contain:paint，测试独立绘制边界能否避免局部残影。它不能隔绝所有宿主 CSS，也不能保证消除 WebView 合成问题。

不改：侧栏、看板与详情面板、手机/768档布局、阴影、滚动条、键盘、锁、余额计算。设置根仅增加专用 data 属性。
